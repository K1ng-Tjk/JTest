# JTest Design System

## Brand
- App: JTest
- Tagline: Тренажёр тестов

## Colors
### Gold Theme (default)
- Primary: #D4A017 (gold)
- Primary Dark: #B8860B
- Primary Light: #F5D76E
- Background: #0A0E1A (deep navy)
- Surface: #111827
- Card: #1A2235
- Text: #F9FAFB
- Text Muted: #9CA3AF
- Accent: #FFD700

### Blue Theme
- Primary: #2563EB
- Background: #0F172A
- Surface: #1E293B
- Card: #1E3A5F

### Night Theme
- Primary: #8B5CF6
- Background: #09090B
- Surface: #18181B
- Card: #27272A

## Typography
- Font: Inter (system fallback)
- Headings: Bold, tight tracking
- Body: Regular, 14-16px
- Mobile-first sizing

## Spacing
- Base unit: 4px
- Components: 12-16px padding
- Cards: 16-20px padding
- Screen padding: 16px

## Borders & Radius
- Cards: rounded-2xl (16px)
- Buttons: rounded-xl (12px)
- Inputs: rounded-xl (12px)

## Shadows
- Card: 0 4px 24px rgba(212,160,23,0.1)
- Button: 0 2px 8px rgba(212,160,23,0.3)

## Animations
- Transitions: 200ms ease
- Page: fade + slide up
- Buttons: scale(0.97) on press

## Mobile
- Max width: 430px (centered on desktop)
- Bottom navigation bar
- Safe area insets respected
